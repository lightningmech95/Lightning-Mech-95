## 📌 Project Description

Tile Slicer is a deliberately simple interactive browser game where
players fetch a tile slab, cut it, count the resulting pieces, and
repeat the process.

It solves absolutely nothing.

And that is precisely the joke.

---

## 🤡 The Problem (that doesn't exist)

The world has many serious problems.

We decided to solve:

> **"What if someone really wanted to cut tiles digitally?"**

Normally, cutting tiles requires actual tiles, tools, physical space
and effort.

Tile Slicer removes all of those requirements.

You only need a browser.

---

## 💡 The Solution (that nobody asked for)

We turned **"cut a tile"** into a web application.

The player:

1. 🧱 Fetches a slab
2. 🔪 Cuts the tile
3. 🔢 Watches the piece counter increase
4. ♻️ Repeats the process
5. 🤔 Questions their decisions

Fast feedback and visible progress create the extremely questionable
motivation of **"one more try."**
